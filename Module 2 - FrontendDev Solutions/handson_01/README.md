# Hands-On 01: HTML5 Semantic Structure & CSS3 Foundations

This folder contains the implementation for Hands-On 01, introducing basic HTML5 semantics and CSS styling fundamentals to build the structural skeleton of the Student Portal application.

## Topics Covered
*   HTML5 Semantic elements (`<header>`, `<main>`, `<nav>`, `<section>`, `<article>`, `<footer>`)
*   CSS Box Model and Universal resets
*   CSS Selectors & Specificity rules
*   Basic layouts and Typography styling
