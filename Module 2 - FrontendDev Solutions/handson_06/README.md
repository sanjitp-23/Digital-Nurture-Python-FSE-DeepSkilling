# Hands-On 06: React Routing & State Management

This folder contains the implementation for Hands-On 06, extending the React Student Portal with client-side routing, global state sharing using the Context API, and state integration with Redux Toolkit.

## Topics Covered
*   React Router v6 (`BrowserRouter`, `Routes`, `Route`, `Link`, `useParams`, `useNavigate`)
*   Global State sharing with React `Context` API
*   Redux Toolkit state stores (`configureStore`, `createSlice`, `useDispatch`, `useSelector`)

## Folder Structure
```text
handson_06/
└── student-portal-react/  # React app root folder
    ├── package.json       # Project configurations mapping

```

## How to Run
1. Navigate to the project directory:
   ```bash
   cd "Module 2 - FrontendDev Solutions/handson_06/student-portal-react"
   ```
2. Install packages:
   ```bash
   npm install
   ```
3. Run local server:
   ```bash
   npm run dev
   ```
