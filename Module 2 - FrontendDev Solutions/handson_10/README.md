# Hands-On 10: API Integration & Advanced State Management

This folder contains the implementation for Hands-On 10, building a centralized API service client using Axios, configuring request/response interceptors, and integrating asynchronous Redux Thunks.

## Topics Covered
*   Centralized API service client using Axios instance
*   Axios request/response interceptors (authorization tokens, data mapping, error parser)
*   Async Thunks using Redux Toolkit (`createAsyncThunk`, `extraReducers`)
*   Global error handling boundaries

## How to Run
1. Navigate to the project directory:
   ```bash
   cd "Module 2 - FrontendDev Solutions/handson_10/student-portal-react"
   ```
2. Install package dependencies:
   ```bash
   npm install
   ```
3. Run Vite dev server:
   ```bash
   npm run dev
   ```
