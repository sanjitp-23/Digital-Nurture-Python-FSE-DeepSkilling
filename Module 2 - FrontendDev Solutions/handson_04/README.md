# Hands-On 04: Async JavaScript, Fetch API & API Integration

This folder contains the implementation for Hands-On 04, adding API integrations to load live server datasets asynchronously, handle API errors, and manage application loading UI states.

## Topics Covered
*   Promises syntax and Async/Await conversion
*   Fetching remote data using JavaScript `fetch` API
*   Axios network requests usage
*   API Loading spinner UI states and error recovery Retry configurations

## Folder Structure
```text
handson_04/
├── index.html     # HTML page with notifications sections and Axios script import
├── app.js         # API requests handler and DOM renderer
├── data.js        # Dataset file
├── style.css      # CSS styles
└── README.md
```
