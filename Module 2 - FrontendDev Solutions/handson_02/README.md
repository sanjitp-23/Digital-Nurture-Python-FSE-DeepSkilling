# Hands-On 02: CSS Flexbox, Grid & Responsive Design

This folder contains the implementation for Hands-On 02, adding responsive styling layouts to the Student Portal application using Flexbox, CSS Grid, and Media Queries.

## Topics Covered
*   CSS Flexbox layout alignment
*   CSS Grid layouts and columns repeat (`repeat(auto-fit, minmax(...))`)
*   Mobile-First design methodologies
*   Fluid typography (`clamp()`) and Viewport Units

## Folder Structure
```text
handson_02/
├── index.html     # Structured HTML with stats bar and course-grid classes
├── styles.css     # CSS flex, grid rules, and responsive media queries
└── README.md
```
