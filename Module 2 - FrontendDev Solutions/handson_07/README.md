# Hands-On 07: Angular — Components, Services, DI, Routing & Forms

This folder contains the implementation for Hands-On 07, building a standalone Angular application with modular components, services, dependency injections, client-side routing, and reactive forms validation.

## Topics Covered
*   Angular CLI operations and Modules mapping
*   Angular Components definition and template bindings (`*ngFor`, `*ngIf`, `[(ngModel)]`)
*   Centralized data fetching services with `HttpClient` and RxJS Observables
*   Reactive Forms and FormGroup input validations

## Folder Structure
```text
handson_07/
└── student-portal-angular/ # Angular app root folder
    ├── package.json        # Dependencies configurations mapping
    └── .gitkeep            # Placeholder file
```

## How to Run
1. Navigate to the project directory:
   ```bash
   cd "Module 2 - FrontendDev Solutions/handson_07/student-portal-angular"
   ```
2. Install package dependencies:
   ```bash
   npm install
   ```
3. Launch Angular local server:
   ```bash
   npm run start
   ```
4. Verify at: [http://localhost:4200](http://localhost:4200)
