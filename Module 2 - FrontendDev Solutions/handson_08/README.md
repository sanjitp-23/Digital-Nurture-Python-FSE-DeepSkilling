# Hands-On 08: Vue.js — Composition API, Vue Router & Pinia

This folder contains the implementation for Hands-On 08, building a Vue.js 3 single-page application using the Composition API, Vue Router, and Pinia state management.

## Topics Covered
*   Vue 3 Single File Components (SFC) and Composition API (`ref`, `reactive`, `computed`)
*   Vue Router navigation (`RouterLink`, `RouterView`, `useRoute`, `useRouter`)
*   Pinia Store management (`defineStore`, `storeToRefs`)

## Folder Structure
```text
handson_08/
└── student-portal-vue/    # Vue app root folder
    ├── package.json       # Project configurations and settings
    └── .gitkeep           # Placeholder file
```

## How to Run
1. Navigate to the project directory:
   ```bash
   cd "Module 2 - FrontendDev Solutions/handson_08/student-portal-vue"
   ```
2. Install package dependencies:
   ```bash
   npm install
   ```
3. Run Vue dev server:
   ```bash
   npm run dev
   ```
4. Verify at: [http://localhost:5173](http://localhost:5173)
