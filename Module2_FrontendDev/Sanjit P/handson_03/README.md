# Hands-On 03: JavaScript ES6+ & DOM Manipulation

This folder contains the implementation for Hands-On 03, integrating dynamic rendering behavior into the Student Portal application using ES6 features, Event delegation, and DOM APIs.

## Topics Covered
*   ES6 variables, Arrow functions, and Template literals
*   Array helper methods mapping (`map`, `filter`, `reduce`)
*   Dynamic DOM element rendering (`document.createElement`)
*   Interactions using Event Listeners and Event Delegation
