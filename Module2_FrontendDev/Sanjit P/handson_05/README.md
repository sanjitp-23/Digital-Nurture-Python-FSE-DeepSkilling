# Hands-On 05: React Fundamentals — Components, Props, State & Hooks

This folder contains the implementation for Hands-On 05, rebuilding the Student Portal using React and scaffolding the application using Vite.

## Topics Covered
*   React setup using Vite build tools
*   Functional Components creation and Props passing
*   State management using the `useState` React hook
*   Side-effects management and API integrations using the `useEffect` hook

## Folder Structure
```text
handson_05/
└── Student-Portal/        # React app root directory
    ├── package.json       # Node package manager configuration
    └── .gitkeep           # Repository directory placeholder
```

## How to Run
1. Ensure Node.js and npm are installed.
2. Navigate to the React project directory:
   ```bash
   cd "Module 2 - FrontendDev Solutions/handson_05/Student-Portal"
   ```
3. Install package dependencies:
   ```bash
   npm install
   ```
4. Run Vite development local server:
   ```bash
   npm run dev
   ```
5. Navigate to [http://localhost:5173](http://localhost:5173) in your browser.
